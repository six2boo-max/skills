# skills

Claude Code 클라우드 세션(아이패드 Claude 앱, claude.ai/code 포함)에서 쓰는 스킬 모음.
`.claude/skills/` 아래의 스킬은 이 저장소로 세션을 열면 자동으로 불러온다.

| 스킬 | 설명 |
|---|---|
| [`lean-research`](.claude/skills/lean-research/SKILL.md) | 토큰을 아끼는 딥리서치. 검색 예산(quick/standard/deep), 병렬 검색, 필요한 부분만 뽑아 읽기, 출처 달린 짧은 보고서 |
| [`report-branching`](.claude/skills/report-branching/SKILL.md) | 내 보고서에서 뻗어나갈 주제(심화·최신화·반론·사례·인접 분야·다음 질문)를 골라 깊게 조사하고, 보고서에 넣을 위치까지 제안 |

사용 예:
- `/lean-research 2026년 국내 전기차 보조금 비교` 또는 "깊게 조사해줘: ..."
- `/report-branching` 뒤에 보고서를 붙여넣거나 파일을 올리고 "이 보고서에서 더 파볼 내용 찾아줘"
