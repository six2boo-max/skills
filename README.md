# skills

Claude Code 클라우드 세션(아이패드 Claude 앱, claude.ai/code 포함)에서 쓰는 스킬 모음.
`.claude/skills/` 아래의 스킬은 이 저장소로 세션을 열면 자동으로 불러온다.

| 스킬 | 설명 |
|---|---|
| [`lean-research`](.claude/skills/lean-research/SKILL.md) | 토큰을 아끼는 딥리서치. 검색 예산(quick/standard/deep), 병렬 검색, 필요한 부분만 뽑아 읽기, 출처 달린 짧은 보고서 |

사용 예: `/lean-research 2026년 국내 전기차 보조금 비교` 또는 "깊게 조사해줘: ..."
